# Mix Check Player

Offline audio test player for checking your own mixes on iPhone.

- Open the GitHub Pages URL in Safari, then Share → Add to Home Screen.
- Tracks you add are stored only on the device (IndexedDB) and are never uploaded.
- Works offline after the first visit (service worker cache).
